## ⚡ Tech Stack & Architecture

- **Core Framework:** React 19 + TypeScript (Strict Mode)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + Custom Design System Tokens (Dark Mode Glassmorphism)
- **Icons:** Lucide React
- **Forms & Email Delivery:** Web3Forms API with Honeypot Anti-Spam
- **Typography:** Geist / Inter + JetBrains Mono

- **Dynamic Island Navigation:** Floating pill navigation with scroll spy, live status beacon, top reading progress bar, and profile portrait avatar.

## 🛠️ Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/maazpathan07/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key_here
```
*(Get a free access key from [https://web3forms.com](https://web3forms.com))*

### 4. Start the development server
```bash
npm run dev
```

### 5. Build for Production
```bash
npm run build
```
